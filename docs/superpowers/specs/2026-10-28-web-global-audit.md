# Web 全局核查结果

## 范围与设计选择

审查当前原生 HTML/CSS/JavaScript 页面、Go API 字段及本地容器部署，共 21 个页面入口；系统页额外覆盖账户、操作记录、诊断三个面板。保留 Go 内嵌静态资源，不新增框架、依赖或前端构建步骤。

采用路由器管理台常用的任务分类：状态、网络、服务、扩展、系统。一级导航负责任务域，二级导航负责同域页面，系统内部用四个面板控制信息量。表单按业务字段组组织，重复项目用带标题的集合，设备及日志用表格；原始诊断信息仅按需展开。

设计参考：[W3C 表单标签](https://www.w3.org/WAI/tutorials/forms/labels/)、[W3C 字段分组](https://www.w3.org/WAI/tutorials/forms/grouping/)、[LuCI 菜单分类](https://github.com/openwrt/luci/blob/master/modules/luci-base/root/usr/share/luci/menu.d/luci-base.json)。分类与字段取舍以本仓库实际能力为准。

## 页面核查矩阵

| 页面 | 发现的问题 | 修改后的布局与内容 |
| --- | --- | --- |
| 总览 | 配置、运行态和固定能力容易混淆；卡片空白过大 | 指标摘要、网络接口、配置摘要、真实服务查询；未知采集明确标记，不展示配置/状态 JSON |
| WAN / LAN | 字段布局松散，连接参数缺少条件显示，草稿与缓存混用 | 两列字段组，模式相关参数条件显示，独立运行信息；静态租约、物理端口集合编辑 |
| WiFi | 固定能力被当作硬件检测；删除/改名可能影响密钥保留 | 接入点集合，明确硬件尚未采集；删除保留其他 AP 密钥，改名要求重新输入密码 |
| 客户端 | 原始数据可读性低，未知采集与空记录混淆 | 搜索表格、数据来源、设备编辑对话框；静态绑定和租约均不声称当前在线 |
| DNS / SSH | 表单字段与列表缺少统一标签和结构 | 设置卡片与字符串列表编辑，SSH 实际运行效果单独说明 |
| 防火墙 | 部分字段不匹配，端口范围不完整 | NAT / UPnP 配置、完整端口转发字段、阻止设备列表 |
| DDNS | 提供商字段结构不匹配 | 四种提供商各自嵌套参数，密码留空保留；明确周期更新服务尚未完成 |
| QoS | 带宽和设备策略字段/单位不匹配 | 总带宽 Mbps，设备限速 Kbps，MAC / IP / 优先级按真实模型保存 |
| 家长控制 / IPv6 | 使用了不同于后端的规则和模式字段 | group / targetMacs / schedule / action；wanMode / PD / RA；不声称执行器已经完成 |
| 插件管理 | 与核心模块重复配置入口，保存路径不统一 | 六个扩展加自定义插件目录；核心模块跳转唯一编辑页，均通过配置接口保存 |
| AdBlock / Traffic / Mihomo | 参数组织不一致，缺少采集边界 | 订阅和规则集合、保留策略、代理配置；无流量采集时不画模拟图表 |
| VLAN / Tailscale / ZeroTier | VLAN、控制平面和网络数组字段不匹配 | vid/name/bridge、controlPlane/loginServer/authKey、字符串网络 ID；保留未知参数 |
| 通用插件别名 | 专用页与通用页内容重复 | 已知插件别名进入同一表单；未知插件保留 JSON 高级编辑，密钥引用可随数组重排 |
| 系统 | 账户、备份、日志、诊断长页堆叠 | 基本设置 / 账户备份 / 操作记录 / 诊断；可搜索记录、展开作业 ID/详情、遮盖诊断密钥 |
| 登录 | 错误反馈、焦点与会话失效处理不完整 | 可见字段标签与错误；过期关闭 modal，恢复登录；跳转内容不改变路由 |

## 共用组件与交互

- 元数据统一页面标题、分类、描述和导航；DOM 文本节点渲染，不拼接不可信 HTML。
- 字段组件统一可访问标签、说明、类型和校验；列表项使用 fieldset/legend，新增删除保留焦点。
- 14–16px 主体和表单文字，限宽内容、两列字段、窄屏单列；表格只在容器内部滚动。
- 独立底部操作栏，长反馈换行且可滚动；内容底部空间随操作栏高度变化，末尾控件可以滚动到可见位置。
- 保存前读取当前配置，仅替换当前草稿分区；保存与生成/运行应用分开报告。失败保留草稿，丢弃不污染其他页面。
- 加载使用序号隔离过期响应；仅总览定时刷新，编辑页面不自动重绘。恢复与应用双向互斥。
- 使用实际健康响应报告仅生成/运行应用模式和重启能力，不从容器名推测。

## 验证

- Go `go test ./...` 全部通过；新增健康响应能力测试通过。
- `tests/web-save-apply.cjs`：23 项浏览器回归。临时后端、独立 SQLite 与配置目录；不修改现有部署数据。
- 24 个页面/面板 × 1440、1024、390、320 宽度：整页无横向溢出，控件关联标签、字号检查通过。
- 真实 API 覆盖配置回读、四种 DDNS、WAN 模式、WiFi 密钥删除/改名、嵌套插件密钥与数组重排、备份/恢复、密码修改、客户端编辑。
- 受控响应覆盖保存失败、HTTP 200 业务失败、管理器冲突、警告、异步作业最终结果、会话过期、慢请求切页、恢复并发。
- 35 条设备记录的搜索、表格与布局验证；桌面/手机截图检查。截图位于 `/tmp/nixos-router-web-audit/after/`，为本机临时验收产物。
- 两轮独立审查发现的问题已增加回归并修复：登录错误不可见、过期 modal、跳转链接、通用插件编辑回退、作业详情缺失，以及后续的密钥数组、恢复互斥、WiFi 重绘边界。
- `backend/web` 与 `web` 三份静态资源一致；语法、格式和 diff 空白检查通过。

## 能力边界

这些结果证明页面布局、表单/API 契约及本地预览部署，不证明真实设备的 NAT 转发、无线、IPv6、限速、DDNS 更新、家长控制定时执行或插件接管完成。运行态采集、部分生成器及执行器仍有未完成项，页面已明确标注。保留既定独立网络管理器互斥决策；没有增加 LAN 改址定时回滚。
