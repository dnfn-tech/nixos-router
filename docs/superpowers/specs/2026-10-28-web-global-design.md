# Web 全局核查与改造

用户授权：核查所有页面、内部组件与部署，并在当前框架中全局修改。
基线：feat/20261028-home-router 未提交基础修复；本地 foundation-local 镜像，127.0.0.1:18080，非特权 UID 1000，bridge 网络及持久化状态目录。

## 发现与选择

21 个入口可渲染，没有页面脚本异常，但并不等于内容或业务正确。现有 10–11px 标签、卡片等高拉伸、顶部动作与长反馈争抢空间、表单缺少关联标签、系统页日志/JSON纵向堆积；客户端把未知采集显示为空列表，总览把链路当互联网，WiFi 固定能力被展示为真实能力。DDNS/QoS/家长控制/IPv6/防火墙/VLAN/Tailscale 的部分编辑字段与后端不匹配。

选择在现有原生 HTML/CSS/JS 下统一组件：保留深色和两级任务导航，单一元数据管理页面名称/分类，通用字段组和数组编辑器统一所有编辑页，表格统一客户端/作业/日志，状态/诊断和编辑隔离。仅修 CSS 不能处理字段契约与状态语义；迁移 React/Vue 会扩大构建和部署成本，均不采用。用户已授权全局修改，具体布局为本次工程判断。

## 页面矩阵

- 总览：服务连接、WAN 链路、接口链路、租约采集、配置摘要；未知不写零，不声称互联网探测成功。
- WAN/LAN/DNS/WiFi/防火墙/SSH：字段组、说明、可编辑配置，独立运行信息；WiFi stub 不报告硬件能力。
- 客户端：搜索、列表、来源、编辑主机名和封禁策略；明确保存不等于实际阻断。
- DDNS：提供商选择及对应嵌套字段；QoS：Mbps 总带宽和 Kbps 设备限制；家长控制：targetMacs/group/schedule/action；IPv6：wanMode/PD/RA。
- 插件管理：可发现所有插件，核心模块跳转唯一配置页，不制造第二份 enable 配置。
- AdBlock/Traffic/Mihomo/VLAN/Tailscale/ZeroTier：按现有生成器字段编辑；标出配置生成与尚未具备的采集/运行能力；通用插件入口保持别名或高级配置入口。
- 系统：常规、账户与备份、作业与日志、诊断四个面板。重启与恢复清晰独立，JSON仅在诊断内按需展开。
- 登录：可见标签、明确错误、键盘可操作。

## 组件与行为

- 不新增 UI 框架或打包步骤，backend/web 权威资源与 web 同步。
- 统一 14–16px 正文字号，内容限宽，字段组两列/窄屏一列；表格仅自身横向滚动；移动导航可关闭、Esc退出。
- 每个控件有 label/id 或 aria-label，数组项有 legend，新增/删除能定位焦点；长错误换行不截断。
- 草稿与已保存配置隔离；失败留输入；原子保存真实后端字段；应用返回业务错误必须展示。
- 页面异步加载有序，切页后旧请求不覆盖新页面；定时刷新只用于状态页，编辑页不自动重绘输入。
- 只展示服务真实报告的部署能力。新增健康响应的应用模式/重启可用性，不根据容器名称猜测能力。
- 不实现新路由执行器，不声称本次 UI 证明真实转发或无线功能完成；保留既有管理器互斥与不新增LAN回滚决定。

## 验收

全入口在 1440/1024/390/320 宽度下无整页溢出；字段有名称，空状态/错误状态明确。隔离后端验证主要配置字段保存后重载一致；保存失败、业务失败、快速切页、放弃草稿、系统页分区和大列表行为回归。保留原有7项浏览器验证意图。Go全套、静态资源一致、浏览器截图，构建本地镜像并保留原数据部署，再只读巡检部署。
