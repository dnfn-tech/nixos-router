# gw 集成软件候选目标

状态：用户于 2026-11-12 确认调整近期目标；实施与验收尚未完成。

## Goal 文本

交付可集成到 nixos-home、满足 gw 现有网络需求的软件候选版本，达到实体硬件验收前提。

完善 nixos-router 通用框架，使其能够承载 nixos-home 中 gw 所需的有线、无线及 IPv4/IPv6 网络功能。完成隔离环境验证、代码审查、固定提交与 nixos-home 集成配置的构建验证，交付可复现的硬件验收候选。设备参数、驱动和秘密由 nixos-home 配置；实体 gw 部署与测试由用户验收后决定。

## 优先范围与顺序

1. 以 nixos-home 的 gw 配置建立功能对照表，明确现有有线与 WiFi 双网段、地址分配、DNS、转发及管理访问规则。逐项记录通用实现、集成配置、验证证据和剩余缺口。
2. 补齐保持现有无线功能所需的通用配置能力，包括 WPA3-SAE、WiFi 6/7 与相应带宽、信道能力校验。硬件驱动和设备参数留在 nixos-home；模拟无线测试不证明实体射频能力。
3. 收尾 IPv6 生命周期、重启恢复、RA MTU/PMTU，验证功能对照表要求的 WAN 模式、PD、LAN 通告、DNS、访问边界和失联恢复。
4. 同步 Web/API 能力声明与实际支持状态，完成上述范围的隔离网络、浏览器、故障恢复及模块回归。
5. 完成独立审查及修复，提交代码和 PR，固定候选提交；完成 nixos-home 集成配置的构建验证、迁移说明和人工恢复说明，提交用户验收。

PPPoE IPv6 等 WAN 模式是否属于近期必需项，以功能对照表为准；已实现或公开声明的支持能力仍须有对应验证，不得伪报支持。

当前源码核查与验收缺口见 [gw 功能对照表](../../gw-integration-matrix.md)。

## 完成条件

- 功能对照表中本轮必需项逐项具备实现与验收证据；gw 功能的删除或降级须有用户明确决定。
- 隔离测试证明 API 应用后的真实地址、路由、DHCP/DNS、转发、访问限制、停用清理及失败/重启恢复；构建和服务 active 状态不能代替真实流量。
- IPv6 重启测试中的 Shell disconnected 已定位并完成重跑；未知结果不计通过。
- Web/API 的编辑、保存、应用和运行结果一致；未支持功能明确呈现限制。
- 候选代码已固定到提交，完成审查和适用检查；验证记录指向对应源码、日志及构建产物，未提交目录不能充当交付版本。
- nixos-home 以固定版本完成 gw 系统配置的评估与构建，记录目标内核能力、驱动、服务互斥和迁移前提；秘密不进入 Nix store。
- 交付用户可审核的软件候选及硬件验收步骤。实体部署、吞吐、射频及硬件稳定性验收由用户后续决定并实际验证。

## 持续边界与后续目标

- nixos-router 保持通用框架；真实网口、地址、运营商参数、驱动及秘密由 nixos-home 承担。
- 保留独立网络管理器互斥、受限 root 执行器与低权限 API、配置版本与应用失败恢复。
- 不增加 LAN 改址倒计时自动回滚；不操作开发宿主网络；本次目标调整不授权实体 gw 部署。
- “完整家用路由”保留为长期目标。QoS、DDNS、家长控制、插件、访客和多 AP 等继续留在后续清单；按 gw 实际需求决定是否纳入本轮必需项。
- 原设计中的 A01–A14 用于追踪完整目标；本轮完成以本文件的功能对照表及完成条件为准，不能据此宣布完整家用路由目标全部完成。
